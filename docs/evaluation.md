# 评测说明

## 测试背景

RLRefine 模型在实际生产环境中经过了人工评测验证。评测由项目测试组同事完成，对 RL 训练后模型（SFT+DPO+GRPO 完整流程）的输出质量进行了多维度人工判定。

核心结论：**RL 训练后模型在关键词提取的准确性、完整性、格式合规和推理质量等维度均显著优于原始 Qwen2.5-7B-Instruct 模型的 Zero-shot 输出。**

---

## 评判维度

| 维度 | 说明 |
|------|------|
| 准确性 | 提取的关键词是否确实是评论的核心要点 |
| 完整性 | 是否遗漏了重要的关键词 |
| 无幻觉 | 关键词是否全部来自原文 |
| 格式正确 | JSON 结构是否正确，字段类型是否符合 Schema |

---

## 已知局限

1. **无标准 Benchmark**：中文电商关键词提取目前没有公认的标准测试集（不同于 NER 有 MSRA/OntoNotes），因此无法进行跨方法的标准化对比
2. **标注主观性**：关键词提取的"正确答案"存在一定主观性，不同标注员可能有不同判断
3. **领域依赖**：当前评测仅覆盖电商评论领域，其他领域（如新闻、医疗）的表现需单独验证
